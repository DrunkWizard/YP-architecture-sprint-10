## Какие данные хранит Медикаменте:

### Персональные данные 
  - Про каждого: 
    - ФИО req 
    - Дата рождения req
    - Телефон req 
    - Email req
  - При заполнении расширенной формы:
    - Адрес прописки 
    - Место работы или учебы


### Финансовые данные

- Данные транзакций
- Информация по зарплате сотрудников

### Медицинские данные
  - Хронические заболевания 
  - Диагнозы
  - Анамнез
  - Результаты анализов 
  - Заключения врача

## Источники данных:
- Журналы приёма пациентов
- Учёт пациентов и платежей
- Медкарты 
- Учёт анализов
- Учёт денежных средств
- Учёт товарно-материальных ценностей

## Анализ процессов:
### Регистрация пациента
Заполнение пациентом форм с персональными данными и попадание их в систему Медикаменте.  
- Требованиями по обеспечению безопасности данных:
  - Хранить и запрашивать только необходимую информацию
  - Пациент должен дать юридическое согласие на обработку персональных данных
  - Чувствительные данные должны храниться в зашифровонном виде
  - Доступ к пероснальным данным пациента должен быть ограничен
  - По требованию пациента должна быть возможность польностью удалить данные о нем из систем 
  - Обеспечить целостность и аудит
  - Использовать маскирование части данных при просмотре сотрудниками
  - Обеспечить безопасность на уровне приложения

### Обработка платежей
Принятие платежей в ККМ и передача данных по ним в систему 1C 
- Требованиями по обеспечению безопасности данных:
  - Хранить только необходимую информацию и ни в коем случае не хранить CVV/CVC
  - Передавать все по зашифрованному каналу TLS 1.2+
  - Шифрование и токенизация 
  - Регулярно обновлять ПО

### Записи в медицинской карте
Занесение медицинским специалистом данных в мед карту пациента
- Требованиями по обеспечению безопасности данных:
  - Хранить только необходимую информацию
  - Данные должны быть доступны только мед специалистом, который принимает пациента
  - Классифицировать данные
  - Обеспечить конфиденциальность при передаче
  - Возможность экстренного доступа к данным в случаях ЧП
  - Шифровать данные

### Запись пациента на прием 
Запись пациента на прием к специалисту. Проходит через администратора, который смотрит свободное время и предлагает варианты
- Требованиями по обеспечению безопасности данных:
  - Хранить только необходимую информацию
  - Минимальные привилегии 
  - Аудит действий администратора

### Учет ТМЦ и закупок обардуования
Работники склада ведут учет обарудования
- Требованиями по обеспечению безопасности данных:
  - Хранить только необходимую информацию
  - Ограничение доступа по ролям
  - Контроль целостности и логирование

## Хранилища данных:
- Общий сетевой диск
- 1С:Бухгалтерия предприятия - работает в файловом режиме
- 1С:Торговля и склад - работает в файловом режиме

## Система тегирования
### Какие теги использовать ? 
- personal (для ФИО, телефонов, etc)
- medical (для диагноза, хроничесих заболеваний, etc)
- financial (для платежей, ЗП, etc)
