| Данные | В чём необходимость защиты | Инструменты защиты |
| ------ | ------ | ------ |
| ПД пациентов | Юридические проблемы, потеря репутации и доверия в случае утечек. Если данные попадут в руки мошенников, то может быть нанесен вред клиентам медикаменте. | Минимальные привилегии, шифрование, DLP-системы(Symantec DLP), IAM для разрграничения доступа (KeyCloak)  |
| Медицинские данные | Врачебная тайна, юридические проблемы, потеря репутации, возможный вред пациенту, в случае вмешательства в данные, можно назначить неправильное лечение. | Минимальные привилегии, шифрование, DLP-системы(Symantec DLP), IAM для разрграничения доступа (KeyCloak) |
| Финансовые данные | Прямые финансовые потери (кражи денег), мошенничество, нарушение законодательства (например, 115-ФЗ о противодействии отмыванию доходов), коммерческая тайна.	 | Минимальные привилегии, шифрование, DLP-системы(Symantec DLP), IAM для разрграничения доступа (KeyCloak), маскирование данных, антифрод-системы, системы защиты банковских транзакций |
| ТМЦ | Прямые материальные потери (кражи, списывание), искажение бухгалтерской отчетности, срыв логистических процессов, мошенничество при закупках. | Системы маркировки и учёта (СКУД для складов, RFID-метки), регулярные аудиты и инвентаризации. |
